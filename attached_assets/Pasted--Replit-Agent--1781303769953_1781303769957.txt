Переделай **ТОЛЬКО блок «Услуги»**. Остальной сайт — шапку, другие секции, глобальные стили, шрифты — НЕ трогай. Сохрани существующее оформление.

Замени блок «Услуги» на 3D-секцию с эффектом **Zoom Gallery (бесшовный зум-поток)**: камера влетает в активную карточку услуги, та раскрывается на весь экран и становится фоном-сценой; затем камера «проныривает» сквозь неё и из глубины вырастает следующая услуга. Переход непрерывный, без швов.

**ТЕХНОЛОГИИ**
- Three.js — карточки-плоскости по оси Z, камера движется вглубь.
- GSAP + ScrollTrigger — привязка полёта камеры к прогрессу скролла.
- Текст услуг — отдельным HTML-слоем поверх WebGL (чёткий, читаемый).

**5 СЛАЙДОВ = 5 УСЛУГ** (заголовок + короткое описание):
1. Парикмахерское искусство
2. Ногтевой сервис
3. Косметология
4. Эстетическая и превентивная медицина
5. Wellness и восстановление

**СЦЕНА**
- 5 карточек-плоскостей выстроены строго в глубину по оси Z, равный шаг (каждые 10 единиц):
  - Карточка 1: (0, 0, 0)
  - Карточка 2: (0, 0, −10)
  - Карточка 3: (0, 0, −20)
  - Карточка 4: (0, 0, −30)
  - Карточка 5: (0, 0, −40)
- Каждая карточка чуть крупнее кадра, чтобы при влёте заполняла весь экран и работала как фон-сцена.

**ДВИЖЕНИЕ (главный механизм)**
- Камера летит вперёд по оси Z, прогресс = scroll progress (0→1).
- Подлетая к карточке, камера **проходит сквозь неё**: карточка увеличивается, заполняет экран, затем уходит за спину (прозрачность падает на самом близком расстоянии — эффект «пронырнул сквозь»).
- Следующая карточка в этот момент **вырастает из глубины**: масштаб маленький → полный, прозрачность 0 → 1.
- В каждый момент один слайд доминирует в кадре. Переход бесшовный.
- Скролл вверх — обратный полёт. Привязка к scroll progress, НЕ к таймеру. Движение с инерцией (lerp).

**ТЕКСТ**
- HTML-текст услуги появляется (fade in), когда её карточка заполняет экран, и исчезает (fade out) при пролёте сквозь неё.

**ДИЗАЙН** (в стиле сайта)
- Премиум, минимализм, бьюти-эстетика.
- Фон секции и `fog` — тёплый бежевый `#EFE9E1`, туман от ~12 единиц глубины (дальние карточки тают в дымке).
- Мягкое освещение, лёгкая глубина.
- Типографика тонкая, крупная, в духе сайта.

**ТЕХНИКА**
- Секция «Услуги» фиксируется по центру (pin через ScrollTrigger), высота ~500vh.
- Оптимизация: `will-change`, ограничь разрешение текстур, плавность обязательна.
- Адаптив: на мобильных шаг по Z и масштаб карточек подгони под экран, скролл плавный.

**ВЫХОД**
Рабочий блок, встроенный в текущий сайт без поломки других секций. Координаты — стартовые, подстрою по превью.

---

🟢 **Сердце эффекта** — момент пролёта сквозь карточку: на самом близком расстоянии её прозрачность падает, а следующая уже растёт из глубины. Это и даёт бесшовность. Не убирай эту логику.

🔴 **Подвох**: если прозрачность гаснет слишком рано — увидишь «дыру» между слайдами; слишком поздно — карточка некрасиво режет камеру. Это правка №1, настраивается порогом fade (на каком расстоянии до камеры начинать растворение). Заложи 2–3 итерации.
