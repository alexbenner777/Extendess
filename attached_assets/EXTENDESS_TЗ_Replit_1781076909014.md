# EXTENDESS — Техническое задание + Брендбук для сборки сайта в Replit
### v2 (обновлено по итогам встречи с заказчиком)

> Документ для AI-ассистента Replit. Скопируй целиком как контекст проекта, затем давай задачи по секциям.
> Тип: один бренд-сайт (6 салонов как раздел). Полный сайт: направления + услуги + онлайн-запись.

---

## 0. Главная задача сайта (приоритет №1)

Бренд = сеть из 6 салонов в Москве, и **состав услуг в салонах РАЗНЫЙ** (где-то есть спа/аппаратные методики/обучение, где-то нет; разные препараты и технологии).

**Ключевая функция сайта:** клиент должен мгновенно понимать — *какая услуга в каком салоне доступна* и как туда записаться. Например: «инъекционная косметология есть на Белорусской, но не на Маяковской». Это центральный сценарий, всё остальное вторично.

## 1. О проекте

**EXTENDESS** — премиальная студия красоты и здоровья нового поколения. Эстетика + превентивная медицина + wellness. Бренд — продолжение французской школы **Dessange** («extend Dessange»): из парикмахерского искусства расширяется в медицину, технологии, восстановление. Сейчас идёт ребрендинг (старое имя Dessange местами ещё встречается).

**Направления:** парикмахерское искусство, ногтевой сервис, эстетическая медицина, косметология, wellness / восстановительные программы.

**Цель:** премиальная витрина бренда + конверсия в онлайн-запись и заявки.

**Референсы тона и уровня:** thelongevitysuite.com (the-longevity-spa), aldocoppola.ru, helms.ru.

**Статус привлечения:** клиенты пока только «с улицы», продвижения не было — сайт первый шаг (далее соцсети, карты).

## 2. Технологический стек (для Replit)

- **Frontend:** React + Vite + TypeScript
- **Стили:** Tailwind CSS (design tokens ниже)
- **Анимации:** Framer Motion — мягкие fade/parallax, без агрессии
- **Локализация:** i18next (RU основной, EN второй); все тексты в JSON-словарях
- **Формы:** React Hook Form + валидация
- **Онлайн-запись:** виджет **YCLIENTS** (iframe/скрипт в модалке; абстракция, чтобы можно было заменить CRM)
- **Карта:** **Яндекс.Карты** — единая карта со всеми 6 точками
- **SEO:** мета-теги, OG, sitemap, hreflang RU/EN (оптимизация по ключам — после сборки)
- **Хостинг:** Replit deployment, mobile-first

## 3. БРЕНДБУК

### 3.1. Логотип
- Текстовый логотип **EXTENDESS**, прописные, увеличенный трекинг (~0.15em), тонкое начертание (Manrope Light/Regular заглавными).
- Версии: тёмный на светлом, белый на тёмном/фото. Минимальный отступ = высота буквы «E».

### 3.2. Цветовая палитра (уточнена заказчиком)
Основа — **чисто белый фон**, чёрный текст, мягкий беж и коричневые оттенки как тёплые акценты. Без ярких цветов.

| Роль | Название | HEX | Где |
|------|----------|-----|-----|
| Фон основной | Pure White | `#FFFFFF` | фон страниц |
| Фон альт. / тёплый | Soft Beige | `#F1EBE3` | чередующиеся секции, карточки |
| Акцент тёплый | Warm Taupe | `#C9B7A2` | линии, hover, подложки |
| Глубокий акцент | Coffee Brown | `#5E4B3A` | кнопки, выделения |
| Текст основной | Noir | `#1A1A1A` | заголовки, текст |
| Текст второстеп. | Stone | `#7A766F` | подписи, captions |
| Тёмная секция | Black | `#000000` | hero-видео фон |

Принцип: 90% — белый/беж, коричневый дозированно (CTA, ховеры, тонкие линии).

### 3.3. Типографика (КРУПНО — это требование)
Жалоба на старый сайт: текст слишком мелкий. Делаем крупно и читаемо и на мобиле, и на десктопе.

- **Шрифт:** Manrope (Google Fonts) — весь сайт.
- H1: Manrope Light, очень крупно; H2–H3 заметно крупнее обычного.
- Body: **минимум 18px desktop / 16px mobile**, межстрочный 1.6–1.7.
- Шкала desktop: H1 64–88 / H2 40–52 / H3 26–30 / Body 18–20 / Caption 14–15.
- Mobile: H1 36–44, Body 16–17. Проверять читаемость на телефоне в первую очередь.

### 3.4. Фото- и арт-стиль (ядро бренда)
**Без людей и моделей.** Только органические формы: цветы, шёлк, лепестки, ракушки, камни/минералы («камушки»), песок, дерево, перламутр. Монохром и тёплая нейтраль, мягкий свет, много воздуха. Эстетика «органический люкс».
- Загруженные 10 референс-изображений = арт-направление (фоны секций, обложки направлений, разделители).
- **Hero:** видео абстрактного цветка (шёлк) на **чёрном фоне** — двигается, loop, без звука, autoplay; mp4 + poster-кадр для мобильных.
- При нехватке материалов — генерировать абстрактные формы/цветы/камни в этой палитре (НЕ людей).

### 3.5. Motion и UI
- Анимации мягкие: fade-in на скролле, лёгкий parallax фоновых текстур, плавный hover 250–400ms.
- Много пустого пространства, минимализм, тонкие линии-разделители (1px Taupe/Stone).
- Кнопки: слегка скруглённые (radius 2–4px), без теней, обводка или заливка Coffee Brown; hover — инверсия.
- Никаких агрессивных поп-апов.

## 4. Структура сайта

Единый сайт:
1. **Главная (лендинг)** — детализация в разделе 5
2. **Направления и услуги** — каталог + где доступно + цены
3. **Салоны** — 6 точек на единой Яндекс-карте + адреса/часы/телефон/запись в конкретный салон
4. **О бренде** — Dessange → EXTENDESS, философия, расширение в медицину/wellness
5. **Контакты** — форма + общий телефон + соцсети
6. (Опц., на будущее) **Блог / Новости**

Шапка: лого, меню, переключатель RU/EN, кнопка «Записаться». Футер: адреса, телефон, соцсети, политика ПД.

## 5. Главная — секции по порядку

1. **Hero** — видео-цветок (чёрный фон), поверх лого/слоган + «Записаться». Слоган: «Красота. Здоровье. Долголетие.» / «Beauty. Health. Longevity.»
2. **Манифест** — короткий абзац о философии (эстетика + медицина + wellness), крупная типографика на белом.
3. **Направления** — 5 карточек с текстурными обложками: Волосы / Ногти / Эстетическая медицина / Косметология / Wellness. Hover — лёгкий зум → каталог.
4. **«Найти услугу рядом»** — блок-навигатор: выбор услуги/направления → показ салонов, где она есть (ключевой UX из раздела 0).
5. **Наследие Dessange** — про французскую школу и экспертизу, фото-текстура сбоку.
6. **Программы долголетия / wellness** — premium-блок (как Longevity Spa).
7. **Салоны** — единая Яндекс-карта с 6 точками + список адресов.
8. **CTA-запись** — крупный блок + виджет YCLIENTS.
9. **Футер.**

## 6. Направления и услуги

**Иерархия (без глубокой вложенности — макс. 2 уровня):**
`Направление → услуга (+ метка: в каких салонах доступна)`

Пример: **Косметология** → инъекционные методики / аппаратные процедуры / обучение. У каждой услуги — теги салонов, где она есть.

- **Парикмахерское искусство** — стрижки, окрашивание, уход, укладки, реконструкция
- **Ногтевой сервис** — маникюр, педикюр, покрытие, уход
- **Эстетическая медицина** — инъекционные / аппаратные (мед-дисклеймер)
- **Косметология** — чистки, пилинги, уходовые программы, anti-age, обучение
- **Wellness / восстановление** — программы долголетия, восстановительные курсы

**Важные ограничения по контенту (по факту от заказчика):**
- Отдельных описаний КАЖДОЙ услуги пока НЕТ — есть описания направлений. Карточка услуги = название + (опц.) цена + теги салонов. Полные описания добавим позже.
- Привязка «услуга → адрес» обязательна (где есть / где нет).
- Цены: есть черновой прайс в PDF (недоработан). До финала — плейсхолдеры `от ___ ₽`.
- Реализовать просто и понятно: клиент не должен «проваливаться» через 5 экранов.

> ⚠️ Запросить у заказчика: финальный прайс и матрицу «услуга × салон».

## 7. Функционал

- **Онлайн-запись:** «Записаться» в шапке и секциях → модалка YCLIENTS. На странице салона — запись в конкретный филиал.
- **Навигатор «услуга → салон»:** фильтр по направлению/услуге, результат — салоны с этой услугой + кнопка записи.
- **Единая карта:** Яндекс.Карты, 6 точек на одной карте, клик по точке → карточка салона (адрес, часы, телефон, запись). НЕ делать 5 разрозненных гео-ссылок.
- **Форма заявки / обратный звонок:** имя + телефон + (услуга/салон опц.) + согласие ПД; отправка на email/Telegram-бот (webhook); валидация телефона.
- **Мультиязычность RU/EN:** переключатель в шапке, контент через i18next, hreflang.
- **Общий телефон** на все соцсети — добавить в шапку/футер (позже от заказчика).

## 8. Адаптивность, перформанс, SEO

- Mobile-first, брейкпоинты 360 / 768 / 1024 / 1440. Читаемость на телефоне — приоритет.
- Hero-видео: на мобильных — облегчённое или poster-кадр.
- Lazy-load, WebP/AVIF, preload Manrope.
- SEO-база: уникальные title/description, OG, sitemap, alt, Lighthouse 90+. Оптимизация по ключевым словам — отдельный этап после сборки.
- Cookie-баннер и согласие на обработку ПД (152-ФЗ).
