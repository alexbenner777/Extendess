Переделай **ТОЛЬКО блок «Услуги»**. Остальной сайт — шапку, другие секции, глобальные стили, шрифты — НЕ трогай. Сохрани существующее оформление.

Замени блок «Услуги» на 3D-секцию с эффектом **Focus Pull (киношный фокус)**: все 5 услуг видны одновременно, расставлены в глубину кадра, но резкой остаётся только одна — та, что в фокусе. При скролле «фокус объектива» плавно перетекает с ближней карточки на дальнюю, остальные мягко размываются (bokeh), как при перефокусировке камеры.

**ТЕХНОЛОГИИ**
- Three.js + постобработка для глубины резкости: `EffectComposer` + Bokeh/Depth-of-Field pass (управляемый параметр `focusDistance`).
- GSAP + ScrollTrigger — привязка фокусного расстояния к прогрессу скролла.
- Текст услуг — отдельным HTML-слоем поверх WebGL (чёткий, читаемый); проявляется только у активной карточки.

**5 СЛАЙДОВ = 5 УСЛУГ** (заголовок + короткое описание):
1. Парикмахерское искусство
2. Ногтевой сервис
3. Косметология
4. Эстетическая и превентивная медицина
5. Wellness и восстановление

**СЦЕНА**
- 5 карточек-плоскостей (~6×4) выстроены в глубину по оси Z, со смещением, чтобы все были видны в кадре (не строго друг за другом):
  - Карточка 1: (−2, 0, 6)
  - Карточка 2: (2, 0.5, 2)
  - Карточка 3: (−1.5, 0, −3)
  - Карточка 4: (2, −0.5, −8)
  - Карточка 5: (−2, 0.5, −13)
- Камера почти статична: (0, 0, 14), смотрит вдоль −Z. fov ~45°.

**ФОКУС (главный механизм)**
- Параметр `focusDistance` плавно движется при скролле от ближней карточки (1) к дальней (5).
- В фокусе — одна карточка: резкая, текст виден. Остальные — мягкий bokeh, тем сильнее, чем дальше от точки фокуса.
- Привязка к scroll progress, НЕ к таймеру. Скролл вверх — фокус едет обратно.
- Активная карточка слегка увеличивается / подсвечивается, усиливая «выбор фокуса».

**ТЕКСТ**
- HTML-текст услуги появляется (fade in) только когда её карточка в фокусе, при расфокусе — fade out.

**ДИЗАЙН** (в стиле сайта)
- Премиум, минимализм, бьюти-эстетика.
- Фон секции и `fog` — тёплый бежевый `#EFE9E1`.
- Мягкое освещение, деликатные тени, кинематографичная атмосфера.
- Типографика тонкая, крупная, в духе сайта.

**ТЕХНИКА**
- Секция «Услуги» фиксируется по центру (pin через ScrollTrigger), высота ~500vh.
- Оптимизация: bokeh-pass настрой экономно (он тяжёлый), `will-change`, ограничь разрешение текстур.
- Адаптив: на мобильных можно заменить тяжёлый WebGL-bokeh на CSS `filter: blur()` по карточкам (упрощённый фокус), скролл плавный.

**ВЫХОД**
Рабочий блок, встроенный в текущий сайт без поломки других секций. Координаты — стартовые, подстрою по превью.
